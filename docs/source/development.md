# Development

Source: <https://github.com/cameronabrams/cfacv>. Bug reports and questions
are welcome as GitHub issues.

Changes arrive as pull requests. CI builds cfacv with gcc 11 and gcc 14, runs
`tests/cv_values.tcl`, and builds this documentation with warnings treated as
errors. Record each change in `CHANGELOG.md` under `[Unreleased]`.
